# Lab 03 - User Role Controlled by Request Parameter

## Objetivo

Analizar cómo una aplicación determina privilegios utilizando parámetros enviados en una petición HTTP.

---

## Conceptos

- Access Control
- Cookies
- HTTP Requests
- Burp Proxy
- Burp Repeater

---

## Lo que aprendí

Reforcé el uso de Burp Suite para interceptar, modificar y reenviar solicitudes HTTP.

Comprendí la diferencia entre Burp Proxy y Burp Repeater y cómo pequeños cambios en una petición pueden modificar el comportamiento de una aplicación vulnerable.
