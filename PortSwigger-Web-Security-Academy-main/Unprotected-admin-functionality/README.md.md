# Lab 01 - Unprotected Admin Functionality

## Objetivo

Comprender cómo una funcionalidad administrativa puede quedar expuesta sin controles de autorización.

---

## Conceptos

- Access Control
- robots.txt
- Hidden Resources
- HTTP Requests
- Authorization

---

## Lo que aprendí

Aprendí la importancia de revisar recursos públicos como `robots.txt` durante la fase de reconocimiento.

También comprendí que ocultar una URL no constituye un mecanismo de seguridad si no existen controles de autorización.
