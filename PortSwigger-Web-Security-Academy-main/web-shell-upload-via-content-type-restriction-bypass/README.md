# Web Shell Upload via Content-Type Restriction Bypass

## Descripción
Bypass de validación basada únicamente en `Content-Type`.

## Objetivo
Comprender por qué validar solo el tipo MIME es insuficiente.

## Herramientas
- Burp Suite
- PortSwigger Web Security Academy

## Lo que aprendí
- Interceptar una subida de archivos.
- Modificar el encabezado `Content-Type`.
- Comprender el riesgo de confiar en validaciones del cliente.
